# ДЗ 1 — сборки Dota 2

Личная коллекция сборок: предметы по этапам игры, прокачка способностей, союзники, противники и игровые ситуации. Можно создавать, просматривать, редактировать, удалять и искать сборки. В начале есть 24 примера — по четыре для каждого из шести героев — и каталог из 53 предметов.

## Запуск

Нужны Node.js 24.19+ и pnpm 11.25.0. Из корня репозитория:

```bash
pnpm install
pnpm dev:hw01
```

Открыть http://127.0.0.1:5181.

```bash
pnpm --filter @frontend-course/homework-01 build
pnpm --filter @frontend-course/homework-01 lint
pnpm --filter @frontend-course/homework-01 preview
```

Preview открывает готовую сборку на том же порту; перед ним нужно остановить dev-сервер.

## Как устроено

Основная сущность — `Build`. Коллекция хранится в `useBuilds`, фильтры и текущая страница — в `App`, несохранённая форма — внутри `BuildForm`. Значения полей контролируются состоянием React. Данные передаются через props, массивы обновляются без мутаций.

`useState` хранит состояние. `useEffect` сохраняет коллекцию после изменений. `useRef` ставит фокус в название формы и позволяет обработчикам работать с последней версией коллекции. `useMemo` кеширует фильтрацию, `memo` вместе с `useCallback` пропускает обновления неизменившихся карточек.

Сохранение — в `localStorage` под ключом `frontend-course-builds-v1`. Оно остаётся после перезагрузки и между сеансами в этом браузере. Пустая коллекция тоже сохраняется. Изображения и каталоги лежат в проекте, сервер для данных не нужен.

Обновление каталога один раз добавляет 16 новых примеров в существующую коллекцию. Сохранённые сборки и их правки не перезаписываются; ранее удалённые примеры и пустая коллекция не восстанавливаются автоматически.

Повреждённое сохранение не перезаписывается автоматически. Восстановление примеров сначала создаёт копию исходных данных под отдельным ключом. При ошибке записи изменения остаются во вкладке и появляется кнопка повторного сохранения.

Фильтры работают вместе: сборка должна подходить под все выбранные условия. Пустая коллекция и отсутствие результатов поиска отображаются отдельно.

План способностей охватывает уровни 1–18. Навык выбирается кликом по ячейке; повторный клик снимает выбор. Проверяются ранги Q/W/E/R; талантам отведено отдельное текстовое поле. Можно оставить часть уровней пустыми. Для сохранения нужны название, хотя бы один предмет и одна способность. В магазине выбирается этап закупки, затем предметы; порядок можно менять, повторные покупки допустимы.

## Проверка и демонстрация

Проверены создание и редактирование с сохранением после перезагрузки, фильтры, валидация формы, подтверждение удаления и мобильная вёрстка. Отдельно проверены операции с коллекцией, пустое и повреждённое хранилище, ошибки записи и повторное сохранение. Установка, сборка и lint прошли в чистой папке.
