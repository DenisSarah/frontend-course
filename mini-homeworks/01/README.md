# Мини-ДЗ 1

Каталог героев Dota 2 с поиском и фильтром по позиции.

```text
src/
  App.jsx          — страница и состояние фильтров
  components/
    Filter.jsx     — поиск и выбор варианта
    List.jsx       — список и пустое состояние
  catalog.jsx      — карточка героя и правила фильтрации
  data.js          — данные героев
  styles.css       — стили
  main.jsx         — запуск React
public/heroes/     — изображения
```

Из корня репозитория: `pnpm install`, затем `pnpm dev`.
