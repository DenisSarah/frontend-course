## Структура

```text
mini-homeworks/
  01/       — каталог героев Dota 2 (React + Vite)
  02/       — команды Dota 2 (React + Express)
  03/       — подбор игроков Dota 2 и оптимизации React
homeworks/
  01/       — сборки Dota 2 (React + TypeScript + localStorage)
```

## Запуск

Нужны Node.js 24.19+ и pnpm 11.25.0. Команды из корня проекта:

```bash
pnpm install
pnpm dev
```

Адрес приложения Vite покажет в терминале, обычно http://127.0.0.1:5173.

Вторая мини-ДЗ:

```bash
pnpm dev:02
```

Клиент и сервер: http://127.0.0.1:5175.

Третья мини-ДЗ:

```bash
pnpm dev:03
```

Приложение: http://127.0.0.1:5177. Варианты для сравнения — в `mini-homeworks/03/README.md`.

Первое большое ДЗ:

```bash
pnpm dev:hw01
```

Приложение: http://127.0.0.1:5181.

```bash
pnpm build
pnpm lint
```
